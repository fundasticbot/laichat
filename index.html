🧠 Laichat

Multi‑panel AI orchestration with roles and routing.
Add a panel and click "Open" to launch an AI.
Each panel opens a new browser tab. Arrange them manually (macOS: hold ⌥ while clicking the green window button).
Roles are stored in localStorage and shared with the userscript. Edit them in the Role Editor.

📝 Role Editor

Define the system prompt for each role. These override the built‑in defaults.
